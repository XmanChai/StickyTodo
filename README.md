# StickyTodo — Windows 托盘待办清单

界面参照 **微软 To Do（Windows 版）**：左侧边栏（今天 / 重要 / 任务 + 自定义列表），右侧白卡任务行。
常驻系统托盘，**零依赖**：用 Windows 自带的 .NET Framework 4.8 与 `csc.exe` 编译，不需要安装 .NET SDK、Python 或 Node。

---

## 一、功能

| 模块 | 说明 |
|---|---|
| 侧边栏 | **白底（与 Windows 标题栏同色）**；顶部「**圆形浅紫底 + 数据库图标 + 我的存储**」区（点它用资源管理器打开数据目录并选中 todos.json）；`今天` / `重要` / `任务` 三个内置视图 + 自定义列表；**Segoe MDL2 线条图标（Win10 自带字体，单色可跟随主色）+ 深色文字**，选中项为浅灰胶囊 + 左侧主题色竖条；列表组上方有一条分格线；**最下方固定「+ 新建列表」** |
| 列表管理 | 「新建列表」与右键「**编辑列表…**」都打开同一个编辑器：**名称 + 图标（30 个 Segoe MDL2 字形，下拉选择）+ 颜色（8 色）+ 背景**；图标默认用列表主色绘制；**图标/颜色/背景点一下就即时生效**（颜色指的是图标与列表主色的颜色），取消编辑会还原；右键还有清空已完成、删除列表（连带其任务）。**列表可以全部删光**（删完不会自动补一个「工作」出来） |
| 内容区 | 背景**整片连续**（含任务行左右两侧的竖带），**只有左上角是圆角**（用抗锯齿路径填充挖角，不是区域裁剪，所以边缘没有锯齿），其余角贴窗口边缘 |
| 标题区 | **大号标题（22pt）：左边带该视图/列表自己的图标**（不加粗；图标框中心与主标题那一行**严格等高对齐**，有副标题时紧跟主标题下方，间距 5px）；`今天` 用**太阳字形**、副标题显示**今天的日期**（如「9月24日, 星期四」），`重要` / `任务` / 自定义列表都不显示副标题 |
| 右上角图标 | 两个：**图钉（置顶）** + **齿轮（都是透明底、白色；图钉只在收起态才带圆角底块）**，后者打开背景设置 |
| 收起（PIN）态 | 点右上角 **📌**：主窗口收起成窄条（480 宽，贴在所属屏幕的**右上角**，不留缩进），**隐藏标题栏、尺寸锁定不可改、永远置顶**，标题区左上角不再做圆角、空列表的提示卡片也不显示。顶部一行是 ☰ + 关闭按钮，**按住这一行可拖动窗口**；点 ☰ 会从左侧**滑出原来的侧栏**（导航 + 列表 + 新建列表），同时把右侧内容**压一层遮罩**，选完视图（或点遮罩/别处）菜单与遮罩一起收回；再点 📌 恢复原样（位置尺寸/置顶/边框都还原，收起期间退出也不会把窄条尺寸记下来） |
| 背景设置 | **每个版块都能单独设背景**（三个内置视图 + 每个自定义列表）：纯色（8 色）、背景图（8 组渐变）、本地图片；内置视图的设置存在 `settings.viewStyles`，列表的存在列表自身。**鼠标一按下色块就立即生效**（父窗口能直接看到效果），「应用」只是收尾关闭，**「取消」会还原成打开前的背景**；在「编辑列表」里打开同一个面板时，点颜色/背景会让**正在编辑的那个列表立刻变**（取消编辑同样会还原） |
| 添加任务 | 底部**与任务行同宽**的纯白圆角输入条（不是通栏），左侧一个圆圈勾选框；**最右侧一颗星**：点亮后新加的任务直接带「重要」标记（**点星星不会丢掉已输入的文字**，焦点会留在输入框里继续输入）；点一下或按 `Ctrl+N` 进入输入，**聚焦后整条白条就是输入区（全高度）**；**点其它任何地方即失焦、恢复成默认的「添加任务」提示**；`Enter` 保存并连续添加，`Esc` 取消 |
| 空状态 | 视图里没有任务时，中间显示半透明卡片（日历+太阳插画 + 一句提示），各视图文案不同 |
| 分组 | 列表视图：未完成任务 + 可折叠的「已完成」组；**`任务` 视图：汇总所有列表的任务，按「未完成」「已完成」分组**，点组标题折叠、右键组标题可批量清除 |
| 拖拽 | 把别的窗口里的**文本 / 图片 / 文件**直接拖到窗口里：文本进「添加任务」输入框（会自动打开输入框并追加）；图片（文件或从浏览器直接拖的图）会**存到数据目录并立刻设为当前版块的背景**；其它文件按文件名拼成任务文字 |
| 清空 | `今天` / `重要` / `任务` 三个内置视图：在**空白处右键**弹出「清空全部（N 条）/ 清空已完成（M 条）」，都带确认；`任务` 视图的「清空全部」= 删除全部任务（自定义列表不弹这个菜单） |
| 任务操作 | 点圆形勾选框 = 完成；单击任务行 = 打开菜单；`F2` 或双击 = 改标题；`Delete` = 删除 |
| 重要 | 任务菜单里「标记为重要」，卡片右侧显示橙色星标；「重要」视图汇总所有星标任务 |
| 到期日 | 菜单里「设置到期日…」可选 **今天 / 明天 / 下周 / 日历自选 / 清除**；卡片右侧显示到期日，今天与逾期为红色 |
| 今天 | 菜单里「添加到「今天」」；**任何入口新加的任务都会记上时间并标为「今天」**，所以在哪一栏加的都能在「今天」看到（跨天后自动离开「今天」） |
| 移动 | 菜单里「移动到列表」可在各列表间转移任务 |
| 已完成分组 | 列表内「已完成 N」分组，点标题行折叠/展开，里面的任务点一下即恢复；右键标题行可批量清除 |

| 背景设置 | 每个列表可选：**纯色**（8 色）、**背景图（8 组渐变）**、**本地图片**（jpg/png/bmp，等比铺满 + 轻雾保证可读）；新建的列表默认按其主题色做同色系渐变 |
| 托盘 | 图标角标显示未完成数；双击切换窗口显隐；右键菜单：显示窗口 / 新建任务 / 今天 / 重要 / 任务 / 设置 / 退出 |
| 单实例 | 重复启动不会开第二个进程，只把已有窗口调到前台 |
| 数据安全 | 原子写盘（临时文件 + 替换）；JSON 损坏时自动备份为 `.broken` 并重建 |
| 旧数据迁移 | 老版本（只有一条清单、无列表/无到期日）的 `todos.json` 会自动升级：建「工作」「个人」两个列表，原任务归入第一个列表 |

快捷键：`Ctrl+N` 光标进添加任务框 · `Ctrl+I` 切换重要标记（输入框开着时切换那颗星，否则切换选中的任务）· `Ctrl+M` 切换窗体模式（收起小窗 / 恢复）· `Ctrl+P` 换背景 · `Alt+1/2/3` 切到 今天 / 重要 / 任务 · `Alt+~` 收起小窗模式下 滑出 / 收起 侧栏菜单 · `Enter` 保存并连续添加 · `Esc` 取消 · `F2` 改标题 · `Delete` 删除选中项。

## 二、编译

```powershell
cd StickyTodo
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物：`dist\StickyTodo.exe`（约 65 KB，单文件，可直接拷走）。

- `build.ps1 -Clean` 先清空 `dist` 再编译。
- 首次运行会自动调用 `make-icon.ps1` 生成 `app.ico`（16/32/48 三尺寸）。
- 脚本按 `csc.exe` 默认的 C# 5 语法上限编译，并显式指定 `/codepage:65001`，保证 UTF-8 源文件里的中文正确解析。

## 三、使用

1. 双击 `dist\StickyTodo.exe`。
2. 托盘出现紫色勾选图标；主窗口默认居中打开，并恢复上次的视图与位置。
3. 关闭窗口 = 收起进托盘（可在设置里改为直接退出）。**退出程序请用托盘右键 → 退出。**

### 托盘右键菜单

```
显示窗口
新建任务…            ← 唤起窗口并把光标放进输入框
────────────
今天（n）
重要（n）
任务（n）
────────────
设置…
退出
```

### 设置项

| 选项 | 默认 |
|---|---|
| 开机自动启动 | 关 |
| 关闭窗口时收起进托盘（不勾选则关闭即退出） | 开 |
| 删除前二次确认 | 开 |
| 启动时显示窗口 | 开 |
| 窗口置顶显示 | 开 |
| 不透明度 | 100% |

开机自启写的是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `StickyTodo` 值，只影响当前用户；关闭该选项即删除该项。

## 四、数据

```
%APPDATA%\StickyTodo\todos.json
```

纯 JSON，可直接备份或迁移。设置窗口里的「打开数据目录」按钮可直接跳转。

结构（v2）：

```json
{
  "version": 2,
  "lists": [ { "id": "...", "name": "工作", "color": -7904072,
               "bgKind": 1, "bgValue": "0" } ],
  "todos": [ { "id": "...", "title": "整理周报", "done": false, "created": 0,
               "priority": 2, "listId": "...", "dueDay": 20260924, "myDay": 20260924 } ],
  "settings": { }
}
```

- `priority`：`0` 普通，`2` 重要。
- `dueDay` / `myDay`：`yyyyMMdd`，`0` 表示未设置。
- `bgKind`：`-1` 未设置（按主题色渐变）、`0` 纯色、`1` 渐变、`2` 图片；`bgValue` 存渐变序号或图片路径。
  （序列化会省略等于 CLR 默认值的成员，所以「未设置」用 `-1` 而不是 `0`。）
- `settings.viewStyles`：内置视图（今天 / 重要 / 任务）各自的主色与背景；
  自定义列表的背景存在 `lists[].bgKind` / `bgValue` 里，列表图标存在 `lists[].icon`（编号见 `Icons.ByKind`，字形取自 Windows 10 自带的 Segoe MDL2 Assets，不需要任何外部图标文件）。

**卸载**：删除 exe 与上述目录即可；若开过自启，先在设置里关掉（或删除注册表 Run 项）。

## 五、源码结构

```
StickyTodo/
├── Program.cs          入口：单实例互斥 + 唤醒事件 + 全局异常兜底
├── Common.cs           Win32 互操作、统一字体、托盘图标绘制、开机自启注册表
├── Design.cs           设计规范：配色/字号/圆角/间距 + 卡片与图标绘制（Icons）
├── Models.cs           TodoList / TodoItem / AppSettings / AppData（DataContract）
├── Store.cs            JSON 读写（原子落盘）、列表与任务 CRUD、视图查询、旧数据迁移
├── TaskList.cs         侧边栏控件（SidebarPanel）+ 任务卡片列表（TaskListPanel）
├── ToDoForm.cs         主窗口：边栏 + 标题栏 + 添加任务条 + 任务操作与右键菜单
├── Dialogs.cs          文本输入对话框（新建/重命名列表）、到期日选择器
├── SettingsForm.cs     设置窗口
├── TrayApp.cs          托盘应用上下文：图标、菜单、窗口生命周期
├── app.manifest        高 DPI + 视觉样式 + 兼容性声明
├── make-icon.ps1       生成 app.ico
└── build.ps1           一键编译
```

### 已知取舍

- 单机本地数据，无账号、无同步、无共享列表；「已分配给我」这类联机能力没有实现。
- 到期日只精确到「天」，没有时间点与提醒通知。
- 任务没有子步骤（Steps）、备注、附件。
- 没有拖拽排序：列表顺序按「未完成优先 → 有到期日的在前 → 到期日升序 → 创建时间」自动排列。
- 使用系统 DPI 感知（非 PerMonitorV2），跨显示器拖动不同缩放比时界面由系统缩放。
